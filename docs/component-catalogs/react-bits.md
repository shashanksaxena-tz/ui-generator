# React Bits Component Catalog

Source: https://reactbits.dev/

React Bits is an open-source collection of 110+ high-quality, animated, interactive, and fully customizable React components. Each component is available in 4 variants: JS+CSS, JS+Tailwind, TS+CSS, and TS+Tailwind.
